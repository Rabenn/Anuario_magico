1. Introducción al Proyecto

El Anuario Mágico es una aplicación de escritorio desarrollada en Java 17+ utilizando el framework JavaFX. El objetivo principal es ofrecer una herramienta administrativa para el personal de Hogwarts que permita gestionar el censo de estudiantes, sus pertenencias (varitas) y su registro visual.

Este proyecto destaca por su capacidad de integrar múltiples formatos de almacenamiento de forma simultánea, garantizando la integridad de la información a través de una arquitectura desacoplada.

2. Arquitectura de Datos

La aplicación implementa una estrategia de persistencia heterogénea. Esto significa que un único objeto "Mago" se fragmenta en tres archivos distintos para optimizar el acceso y la lectura:

Archivo Formato Datos Almacenados
nombres.json JSON Identificadores únicos (UUID), nombres completos y casas asignadas.
varitas.xml XML Descripción técnica de la varita asociada a cada ID.
imagenes.csv CSV Fotografías del alumnado convertidas a cadenas de texto Base64.

3. Requisitos e Instalación

Requisitos del Sistema

  • Java Runtime Environment: Versión 17 o superior.
  • Librerías gráficas: Módulos de JavaFX (Graphics, Controls, FXML).
  • Dependencias: Jackson Databind (para JSON) y JasperReports (para PDF).

Instalación

Descomprima el archivo del proyecto en un directorio con permisos de escritura. Asegúrese de que los archivos base (nombres.json, etc.) se encuentren en la misma carpeta que el ejecutable para que la carga inicial sea correcta.

4. Manual de la Interfaz Gráfica

La interfaz ha sido diseñada siguiendo el patrón Material Design adaptado a un entorno mágico:

  • Panel de Control Superior: Contiene el buscador inteligente, el filtro por categorías y el selector de idioma.
  • Área de Navegación Central: Una cuadrícula (TilePane) que muestra tarjetas dinámicas. Cada tarjeta cambia su color de borde según la casa del mago:
    • Rojo: Gryffindor
    • Verde: Slytherin
    • Azul: Ravenclaw
    • Amarillo: Hufflepuff
  • Paginador Inferior: Permite gestionar grandes volúmenes de datos dividiéndolos en bloques de 8 alumnos por página para mejorar el rendimiento.

5. Guía de Operaciones (CRUD)

Añadir un nuevo registro

  1. Haga clic en el botón con el icono "+".
  2. Introduzca el nombre del alumno. El botón "Guardar" se bloqueará si el nombre está vacío.
  3. Seleccione la casa y describa la varita.
  4. Carga de imagen: Utilice el selector para buscar un archivo JPG o PNG. El sistema lo convertirá automáticamente a binario.
  5. Pulse Guardar: el sistema sincronizará los tres archivos de datos instantáneamente.

Búsqueda y Filtrado

El buscador no requiere pulsar "Enter". Simplemente escriba y la interfaz se actualizará. Puede elegir buscar específicamente por nombre, casa o el material de la varita usando el desplegable adyacente.

Eliminación (Expulsión)

Para eliminar a un mago, entre en sus detalles y pulse Eliminar. Se mostrará una alerta de confirmación con la foto del mago para evitar borrados accidentales.

6. Motor de Reportes (JasperReports)

La aplicación permite exportar datos en formato PDF profesional, ideal para impresiones oficiales:

  • Reporte General: Accesible desde el botón "PDF" de la pantalla principal. Incluye a todos los magos filtrados actualmente en una lista tabular.
  • Ficha de Alumno: Accesible desde la vista de detalles. Genera un documento individual con la foto ampliada y los datos técnicos de la varita.

Nota: El proceso de generación puede tardar unos segundos dependiendo del tamaño de las imágenes cargadas.

7. Resolución de Problemas

¿No se ven las imágenes?
Compruebe que el archivo imagenes.csv tiene el formato correcto (id, base64) y que no hay líneas corruptas.
¿Error al guardar?
Asegúrese de que la aplicación tiene permisos para escribir en la carpeta actual y que ningún otro programa (como un editor de texto) tiene bloqueados los archivos .json o .xml.
